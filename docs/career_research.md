The first two examples request experienced candidates; the latter examples also require German communication. They guide transferable skills, not a claim that a portfolio substitutes for professional experience or language proficiency.

## Complement to existing work

The retail project already covers SQL KPIs, segmentation and dashboards. The churn and weather projects cover model evaluation. This project adds **dbt, fact/dimension modelling, data lineage, interval contracts, reproducible source snapshots and decision-rule verification**. It supports applications for junior Data Analyst, Operations Analyst, Data Quality Analyst and developing Analytics Engineer roles.

## Honest use in applications

Describe this as an **independent portfolio project**. Do not claim employment at an energy company, production deployment, actual savings or expert dbt/Power BI proficiency. Before interviews, run the project and complete the walkthrough. AI assistance was used to develop this repository; ownership of the explanation and future improvements should come from hands-on study and work.
